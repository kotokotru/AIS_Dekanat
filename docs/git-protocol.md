# Git-протокол АИС «Учебный деканат»

Модель ветвления — GitHub Flow: стабильная ветка `main` и короткоживущие ветки под задачи бэклога.

| Правило | Значение |
|---|---|
| Основная ветка | `main` — всегда стабильна. Прямые коммиты запрещены правилом защиты ветки. |
| Новые функции | `feature/<ключ-задачи>-<кратко>`, например `feature/DEAN-42-gpa-calculation` |
| Исправления | `bugfix/<ключ-задачи>-<кратко>`, например `bugfix/DEAN-57-scholarship-rounding` |
| Срочные исправления | `hotfix/<ключ-задачи>-<кратко>` от `main`, например `hotfix/DEAN-61-order-sign-date` |
| Условие создания PR | Модуль собирается без ошибок, xUnit-тесты проходят, OpenAPI обновлён, ветка актуальна с `main`, в описании указан ключ задачи |
| Правило слияния | Минимум 1 одобрение и успешные тесты; для «Успеваемость и GPA» и «Стипендии» — одобрение ведущего разработчика; Squash merge, ветка удаляется |

Чек-лист Code Review — в шаблоне [`.github/pull_request_template.md`](../.github/pull_request_template.md).
