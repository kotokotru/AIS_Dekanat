# AIS_Dekanat — АИС «Учебный деканат»

Вариант 10. Модули: приказы по контингенту, успеваемость (балльно-рейтинговая система), расчёт средних баллов (GPA).

Автор: Леонов Тимофей Андреевич, группа И14-23-9.

## Структура репозитория

| Папка | Назначение |
|---|---|
| `src/AIS.Dekanat.Core` | доменная модель: студенты, приказы, оценки БРС, расчёт GPA |
| `src/AIS.Dekanat.Infrastructure` | EF Core, интеграция с системой БРС и 1С |
| `src/AIS.Dekanat.UI` | клиентское приложение деканата (WPF, MVVM) |
| `tests/AIS.Dekanat.Tests` | модульные тесты xUnit |
| `docs/architecture` | диаграммы C4 и записи ADR |
| `docs/openapi` | спецификация API модуля успеваемости |
